# setstatusbot
## A plugin for the Matrix-Synapse bot framework [Maubot](https://github.com/maubot/maubot)
_Pre-Release version. 
For testing only._

Set the presence of the calling user to the message submitted. Keeps it updated by resubmitting every 60 seconds. This keeps Element and other non-standard, non-msc following apps from overwriting it.

`!setstatus <status message to display>`
